# Общее представление библиотеки
`geometric_lib` предоставляет набор утилит для работы с числовыми значениями геометрических фигур. 
## Философия библиотеки
В основе решения лежит функциональное программирование. Данная библиотека предоставляет функции для работы с конкретными числовыми значениями группированными по названиям класса геометрических фигур. Основная цель библиотеки - быть удобным и читабильным дополнением к базовым вычислениям - избавить пользователя от необходимость реализовывать тривиальные функции базовых формул геометрии в своём проекте тем самым делая его код чище.

```py

    """
    Вычисляет площадь квадрата с длинной ребра a. Возвращаемый тип данных соответствует типу данных параметра a.

        a (float|int) - длина ребра квадрата.

    Возвращает:
        S (float|int) - площаль квадрата.
    """
    ...
```

Пример вызова:
```py
>>> import geometric_lib.square as square
```
